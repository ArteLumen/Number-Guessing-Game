# Number Guessing Game in C

A simple, fun, and interactive console-based Number Guessing Game written in C.

---

## 🎮 How the Game Works

1. The computer randomly selects a secret number between **1 and 100**.
2. You enter your guess in the console.
3. The game will give you hints:
   - If your guess is too high, it will tell you to choose a **LOWER** number.
   - If your guess is too low, it will tell you to choose a **HIGHER** number.
4. Once you find the correct number, it displays your total number of attempts!
